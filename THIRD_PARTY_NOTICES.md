# Third-party notices

## TimesFM source

The local forecast service uses Google Research TimesFM source revision `v3.0.0` from https://github.com/google-research/timesfm. The source repository is Apache-2.0 licensed. Preserve the upstream license text when redistributing source or build artifacts.

## TimesFM 3 pretrained weights

The default checkpoint is `google/timesfm-3.0-pytorch`. Google Research currently distributes TimesFM 3 pretrained weights under `timesfm-non-commercial-license-v1.0`, restricted to non-commercial, non-production use. This repository enables the checkpoint only for local development and evaluation. Production use requires a separately approved license or service.
